# Atlas — Test Plan (v1)

Scoped for Mode 1 (scripted audio playback) demo. Generated by `/plan-eng-review`.

> v0.2 modes (interactive, Vexa) have separate test concerns deferred with the modes themselves.

## Affected surfaces

- `apps/agent/src/memory/store.ts` — patch application, hybrid merge, revision history
- `apps/agent/src/memory/patchQueue.ts` — FIFO ordering by utteranceId
- `apps/agent/src/agents/unified.ts` — unified suggestion+classifier, structured output streaming
- `apps/agent/src/agents/extractor.ts` — JSON patch generation
- `apps/agent/src/agents/verdict.ts` — post-call verdict synthesis
- `apps/agent/src/agents/trainingDelta.ts` — post-call Training Delta synthesis
- `apps/agent/src/agents/email.ts` — draft follow-up email
- `apps/agent/src/replay/timer.ts` — transcript replay event firing on `timeupdate`-like cadence
- `apps/agent/src/sse/handler.ts` — snapshot + stream-forward on reconnect
- `apps/agent/src/llm/wrapper.ts` — cost tracking, retry, telemetry, gateway routing
- `apps/web/components/MemoryPanel.tsx` — animated entry, hover provenance, BANT color coding
- `apps/web/components/WhisperBar.tsx` — pulse animation, token streaming, abort handling
- `apps/web/components/TranscriptView.tsx` — speaker labels, timestamps, scroll behavior
- `apps/web/components/PreCallBrief.tsx` — collapsed-by-default header
- `apps/web/app/demo/[script]/page.tsx` — audio playback, replay sync
- `apps/web/app/post-call/[id]/page.tsx` — verdict + Training Delta render + cost/latency footer

## Critical paths (must work for demo)

1. **Scripted Mode 1 end-to-end:** open `/demo/maya` → click play → audio plays → memory panel populates within ~600ms of each utterance → whisper bar fires on detected objections → call ends → post-call view shows verdict + Training Delta + cost/latency footer
2. **Scripted determinism (THE test):** play Maya twice → identical Training Delta both times. Submission email screenshot must match exactly what the hiring panel sees.
3. **Cost ceiling enforcement:** simulate 6 sessions from one IP → 6th rejected with "demo capacity reached"
4. **Reconnect resilience:** open `/demo/maya`, click play, refresh page mid-stream → memory panel reflects current state via snapshot replay
5. **Pulse-then-suggestion timing:** "Atlas is listening" pulse appears within 50ms of customer utterance → either fades silently (NO_SUGGESTION) or fills with streamed suggestion text

## Edge cases (handled in implementation, not separate tests)

- Empty utterance from replay: pipeline ignores, no patch generated
- 2 facts about budget within 5 seconds: hybrid merge — typed-key dedup applies, prior version moves to `revisions[]`
- STT confidence in fixture < 0.7: utterance flagged `derivedFromLowConfidence: true`, UI fades to 60% opacity
- Audio playback interrupted (tab backgrounded): replay timer pauses on `pause` event, resumes on `play`
- User navigates away mid-call: SSE connection closes cleanly, server-side state persists, can resume

## What we explicitly do NOT test in v1

- Mode 2 / Mode 3 (deferred to v0.2)
- OpenAI Realtime API mocking (Mode 2 only)
- Vexa integration (Mode 3 only)
- Component visual regression (out of scope for take-home)
- Load / chaos / failure injection (cost ceiling provides containment)
- Security / auth (single-user demo)
- Accessibility comprehensive audit (basic semantics only)

## LLM evals — minimal scope

For each scripted call, manually verify before submission:
- Unified model classification accuracy ≥ 8/10 on customer utterances (eyeball, not formal)
- Extractor doesn't hallucinate facts (no fact references content not in utterance)
- Suggestion bar cites specific memory items in `groundedInUtteranceIds` when `shouldSuggest === true`
- Verdict reasoning is grounded in extracted qualSignals (not generic)
- Training Delta sections all populated with non-trivial, script-specific content
- Cost/latency footer numbers are sensible (no $5 calls, no 10-second p50)

If any fail on the 3 scripted calls, fix the prompt or schema before submitting. The Training Delta accuracy is non-negotiable — it's the screenshot.
